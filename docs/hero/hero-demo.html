Animated concept demo: a Claude Code chat delegates a task to a Codex sub-agent through Fluxion's MCP server. The call is asynchronous — dispatched, polled, then retrieved — and Codex edits three files and returns the result with one-click revert. Fluxion's macOS menu-bar app shows remaining quota and token usage for Claude, Codex, and Antigravity in a Dynamic-Island notch.
