Fluxion — delegate scoped tasks across Codex, Claude Code, and Antigravity through one local MCP server

Animated concept demo with staged data. In Claude Code, the user asks for retry logic in a messaging gateway. Claude splits the task between a Codex sub-agent and an Antigravity sub-agent, running in parallel through Fluxion's local MCP server; they change three files and the result comes back to Claude as a reviewable, revertible change set. Fluxion's macOS notch then shows remaining quota for Claude, Codex, and Antigravity; when Codex's window resets, Fluxion notifies and Auto-Pings to start the next one. Finally a task is sent from a phone chat and the Mac replies.
